# AI Adaptive Educational Robot 🤖

A speech-driven adaptive learning educational robot with autonomous edge intelligence
and optional cloud-assisted retraining.

## Key Features
- Offline-first voice interaction
- Multilingual speech (English, Hindi, Marathi)
- Adaptive learning based on user performance
- Personalized interaction via vision-based identification
- Screenless, voice-only educational robot

## Tech Stack
- Python
- Raspberry Pi (deployment)
- Offline STT / TTS
- Computer Vision
- Machine Learning (edge-first)

## Project Status
LEVEL-3: Foundation Completed & Adaptive Learning is in progress
